## Library usage (JavaScript/TypeScript)
```ts
// Example: import and use a function from your library
import { doThing } from 'your-lib';

const result = doThing({ option: true });
```

## CLI usage
```bash
# Install
npm install -g your-cli

# Run a command
your-cli run --input path/to/file
```

## REST API
```bash
curl -sS -X POST https://api.example.com/v1/do-thing \
  -H 'Content-Type: application/json' \
```
