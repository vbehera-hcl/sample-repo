# Usage & Installation

Currently no installable package or CLI is defined. Use this template and update once code exists.

## Local development
1. Clone the repo.
2. Add your source files under `src/`.
3. Update `docs/API.md` with exported APIs.
4. Add runnable examples in `docs/EXAMPLES.md`.

## Publishing
- For npm: add `package.json`, set `main`/`exports`, and publish.
- For Python: add `pyproject.toml` and publish to PyPI.
- For Go: add `go.mod` and tag releases.
